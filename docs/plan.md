# 实施计划

## 目标拆解

### 目标 1：评论汇总分析

- 支持导入评论数据文件
- 提取高频词与核心议题
- 判断评论整体情绪倾向
- 拆分积极 / 消极 / 中性评价比例
- 输出代表性正面与负面观点

### 目标 2：弹幕时间轴分析

- 支持导入 B 站弹幕 XML / JSON
- 基于时间点聚合弹幕密度
- 生成可缩放的时间轴曲线图
- 支持秒级到分钟级聚合切换
- 自动识别高密度区间
- 对高密度区间的弹幕内容做重点分析与总结

## 技术方案

### 前端

- `React + TypeScript + Vite`
- `ECharts` 绘制弹幕密度时间轴
- 文件上传、统计卡片、区间聚焦面板

### 后端

- `FastAPI`
- `jieba` 做中文分词
- `csv / json / xml` 解析评论与弹幕数据
- OpenAI 兼容接口生成 AI 复盘摘要

## 里程碑

1. 完成前后端项目骨架与本地运行环境
2. 完成评论与弹幕文件导入
3. 完成评论高频词、情绪分析和观点提取
4. 完成弹幕密度曲线与高峰区间分析
5. 接入 AI 摘要与 UI 打磨
6. 补充数据导出、B 站链接抓取与部署方案

## 当前实现边界

- 当前版本优先支持“本地文件导入分析”
- B 站站内直接抓取暂未接入，避免被登录态 / 风控 / 接口变更卡住
- 情绪分析先用轻量词典方法，后续可升级为模型分类
