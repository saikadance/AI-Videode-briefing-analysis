# 当前状态存档

更新时间：2026-05-15

## 当前可用能力

- 支持主页面“文案文稿分析”模式，直接调用 GPT 对视频脚本 / 文稿做专业点评
- 支持输入 B 站视频链接、`b23` 短链或 `BV` 号直接抓取视频信息、评论和弹幕
- 支持本地文件导入作为补充分析模式
- 评论分析支持：
  - 高频词统计
  - 正面 / 负面 / 中性占比
  - 代表性评论抽取
  - 基于词典、否定词、程度词、转折语气的增强型情绪判断
- 弹幕分析支持：
  - 秒级密度统计
  - 时间轴缩放查看
  - 前端本地切换聚合粒度，不需要重新请求
  - 高密集区间识别
  - 高峰点标记与区间摘要
- AI 复盘摘要支持：
  - 通过 `OPENAI_API_KEY + OPENAI_BASE_URL + OPENAI_MODEL` 调用
  - 当前已确认 `https://llm-proxy.tapsvc.com/v1` 可用
  - 摘要已改为结构化输出并按分段展示
- 文案文稿分析支持：
  - 后端新增 `/api/analyze/copy`
  - 前端主页面已切为默认主模式
  - 直接调用 GPT，不走本地规则回退摘要
  - 默认优先使用 `GPT-5.5`
  - 使用本地 skill：[skills/video-copy-analyst/SKILL.md](<E:\A 弹幕评论复盘\skills\video-copy-analyst\SKILL.md>)

## 当前主要配置

后端环境文件：

- [backend/.env](<E:\A 弹幕评论复盘\backend\.env>)

关键字段：

- `OPENAI_BASE_URL=https://llm-proxy.tapsvc.com/v1`
- `OPENAI_MODEL=gpt-5.4-mini`
- `OPENAI_COPY_MODEL=gpt-5.5`
- `BILIBILI_COOKIE=...`

启动方式：

- 双击 [start_app.cmd](<E:\A 弹幕评论复盘\start_app.cmd>)

访问地址：

- `http://127.0.0.1:8000`

- 代表性评论支持长文本展开 / 收起

  - 正负面关键词并入更宽的双列“评论摘要对照”面板

## 当前已知限制

- B 站部分视频的评论接口仍可能受登录态、风控或视频类型影响
- 弹幕分段抓取已可用，但不同视频的弹幕丰富度差异很大
- 评论情绪判断已增强，但仍属于规则增强方案，对反讽、梗和强上下文评论不一定稳定
- AI 摘要调用失败时当前会回退本地摘要，后续可考虑在 UI 上明确显示调用状态
- 文案分析目前默认输出为结构化长文本，后续可继续做成更明显的“问题 / 改法 / 可替换文案”卡片布局
- 视频后台数据分析能力尚未接入，当前仍以文稿判断为主

## 建议下次测试重点

- 验证不同类型视频下评论抓取数量是否稳定
- 验证时间轴高密集点标记是否仍有漏标 / 误标
- 验证 AI 摘要在不同视频上的排版质量和结构一致性
- 验证评论情绪判断对“阴阳怪气 / 反讽 / 模糊评价”的表现
- 验证文案文稿分析在不同稿件类型下的稳定性，尤其是采访稿、游戏安利稿、人物故事稿
- 验证 GPT 输出是否需要继续拆成更强的模块化排版
- 验证 `GPT-5.5` 在长稿、采访稿、安利稿上的分析稳定性

## 后续可继续改进的方向

- 在 UI 上明确显示“AI 已调用 / 已回退本地摘要”
- 支持可选 Cookie 更新入口，而不必手动改 `.env`
- 进一步优化时间轴高峰识别策略
- 引入 AI 二次评论情绪判定，提升复杂语境准确率
- 增加导出报告能力
- 给文案分析增加可选模板，如“B 站长视频 / 短视频 / 采访稿 / 评测稿”
- 接入视频后台数据分析，并与文稿、评论、弹幕形成统一综合分析页
